Les fichiers de ce dossier sont réservés à la fiche Chrome Web Store et **ne doivent pas être inclus dans l’archive de l’extension**. Les visuels doivent être capturés depuis une installation locale réellement chargée, avec des données fictives et sans nom, e-mail, URL privée, contenu sensible ou jeton.

## Procédure

1. Chargez le dossier AITools via `chrome://extensions` en mode développeur, puis ouvrez le popup ou un nouvel onglet AITools.
2. Saisissez uniquement les données fictives indiquées ci-dessus ; n’utilisez aucune capture de page réelle.
3. Redimensionnez la fenêtre Chrome à **1280 × 800** pour les captures de fiche. Conservez les coins carrés et l’image pleine zone.
4. Enregistrez chaque image PNG sous le nom cible, relisez la lisibilité à taille réduite puis chargez au maximum cinq captures dans l’ordre ci-dessus.
5. Créez l’image promotionnelle 440 × 280 séparément. Elle doit exprimer la marque, et non simplement réduire une capture d’écran.

Les formats et dimensions proviennent de la documentation officielle Chrome Web Store.[1]
